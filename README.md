# PRI — Réseaux bayésiens pour la modélisation du risque

Projet de recherche individuel, INSA, novembre 2026 à janvier 2027.

Découvrir les réseaux bayésiens, puis coder un prototype Python qui apprend leurs
probabilités à partir de données. Application : une aide à la décision en
maternité (par exemple césarienne ou non), sur des données synthétiques.
