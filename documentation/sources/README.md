# Sources

Trace structurée du travail de documentation : un fichier par thème. Chaque
ressource a son lien, la date de consultation et un commentaire sur son utilité.

| Fichier | Thème |
| --- | --- |
| [`01_cours_stanford_cs221.md`](01_cours_stanford_cs221.md) | Vidéos et slides du cours de référence |
| [`02_probabilites.md`](02_probabilites.md) | Rappels de probabilités et bases mathématiques |
| [`03_cas_maternite.md`](03_cas_maternite.md) | Aide à la décision médicale, contexte maternité |
| [`04_outils.md`](04_outils.md) | Python, Git, Sphinx, bibliothèques, assistance par IA |

## Comment remplir une ligne

- **Date** : le jour où la ressource a été consultée.
- **Utilité** : forte, moyenne ou faible.
- **Commentaire** : ce que la ressource apporte, ses limites, et à quoi elle a
  servi dans le projet. Une ressource jugée inutile reste dans la liste, avec la
  raison : cela évite d'y revenir.
